# ScreenLingo

Лёгкий переводчик текста в выделенной области экрана для Windows 10/11. Работает из системного трея и показывает перевод поверх исходного содержимого.

## Возможности

- `Ctrl+Shift+T` — выделить область и перевести найденный текст.
- `Ctrl+Shift+R` — выделить область и скопировать исходный OCR-текст.
- Перевод целыми абзацами с сохранением контекста.
- Адаптивные фон, цвет, перенос и размер текста.
- Закрытие оверлея любым кликом без блокировки приложения под ним.

## Использование

1. Скачайте архив из раздела Releases и распакуйте его.
2. Запустите `ScreenLingo.exe`. Приложение появится в системном трее.
3. Нажмите `Ctrl+Shift+T` и выделите область с английским текстом.
4. Перевод появится поверх исходного содержимого и автоматически исчезнет через заданное время.
5. Любой клик немедленно скрывает перевод, при этом передаётся приложению под ним.

Перевод выполняется целыми абзацами, чтобы сохранялся контекст. Оверлей подбирает светлый или тёмный цвет текста и фон по исходному изображению, переносит строки и уменьшает шрифт при необходимости.

Параметры находятся в `ScreenLingo.ini` рядом с программой. После изменения перезапустите приложение.

## Важно

- OCR выполняется локально средствами Windows.
- Для перевода используется сетевой endpoint Google Translate, поэтому нужен интернет. Это MVP без официального API-ключа; для стабильного распространения нужно подключить официальный API.
- Английский языковой пакет OCR должен быть установлен в Windows: **Параметры → Время и язык → Язык и регион → Английский → Параметры языка → Базовый ввод**.
- Приложение не сохраняет снимки экрана.

## Сборка

Проект собирается штатным компилятором .NET Framework, входящим в Windows:

```powershell
.\build.ps1
```

Готовый файл появится в `dist/ScreenLingo.exe`.
