# Changelog

## 0.8.4 — 2026-08-11

- Добавлена многоразмерная иконка в ресурсы `ScreenLingo.exe`.
- Иконка теперь отображается в Проводнике, свойствах файла и на панели задач.
- Добавлен воспроизводимый генератор `ScreenLingo.ico`.

## 0.8.3 — 2026-08-09

- Удалены фиолетовые края и буквы, возникавшие рядом с границей прозрачного окна.
- Перевод теперь принудительно обрезается внутри непрозрачно восстановленной области.
- На гладких фонах маска очистки расширяется до границ целых OCR-строк.
- Усилено удаление сглаженных краёв исходных символов.
- Добавлен тест на отсутствие полупрозрачных пикселей, смешивающихся с `TransparencyKey`.

## 0.8.2 — 2026-08-09

- Добавлено автоматическое определение разбросанного макета с несколькими текстовыми блоками.
- Пространственно разделённые подписи больше не объединяются в один большой абзац.
- Для коллажей и цитат заголовок объединяется только с ближайшей подписью под ним.
- Добавлен регрессионный тест группировки разбросанного текста.

## 0.8.1 — 2026-08-09

- Исправлено наложение подписи интервала наблюдения на поле значения при увеличенном DPI.
- Сокращена подпись кнопки сброса горячих клавиш.

## 0.8.0 — 2026-08-09

- Добавлен выбор сервиса перевода: Google, DeepL и LibreTranslate.
- Добавлены API-ключ DeepL и настраиваемый адрес собственного сервера LibreTranslate.
- API-ключ сохраняется с шифрованием Windows DPAPI для текущего пользователя.
- Добавлено переназначение четырёх глобальных горячих клавиш с проверкой конфликтов.
- В настройки добавлены время показа перевода и интервал наблюдения.
- Меню трея автоматически отображает выбранные сочетания клавиш.

## 0.7.0 — 2026-08-09

- Исходные буквы удаляются по пиксельной маске вместо сплошной прямоугольной подложки.
- Фон под текстом локально восстанавливается из окружающих пикселей.
- Перевод рисуется единым сглаженным графическим слоем вместо набора `Label`.
- Добавлен подбор цвета, жирности, шрифта и размера перевода по исходному изображению.
- Windows OCR теперь сохраняет координаты отдельных слов для более точного наложения.

## 0.6.0 — 2026-08-09

- Добавлено окно настроек языка перевода в меню системного трея.
- Выбранный язык сохраняется в `ScreenLingo.ini` и применяется ко всем следующим переводам.
- Добавлены 13 языков назначения; текущим сервисом остаётся Google Translate.

## 0.5.0 — 2026-08-09

- Добавлен повтор перевода последней области по `Ctrl+Shift+Y`.
- Добавлен режим наблюдения за изменяющимся текстом по `Ctrl+Shift+W`.
- Добавлено увеличительное стекло и замороженный снимок при выделении области.
- Добавлена поддержка Per-Monitor DPI Awareness V2 для нескольких мониторов.

## 0.4.2 — 2026-08-09

- Добавлена новая цветная иконка ScreenLingo в системном трее.

## 0.4.1 — 2026-08-09

- Удалена функция автозапуска через реестр Windows из-за ложного срабатывания Microsoft Defender.
- Добавлены метаданные версии 0.4.1.

## 0.4.0 — 2026-08-09

- Перевод выделенной области по `Ctrl+Shift+T`.
- Копирование исходного OCR-текста по `Ctrl+Shift+R`.
- Перевод строк с контекстом целого абзаца.
- Адаптивные фон, цвет и размер текста в оверлее.
- Закрытие оверлея кликом в любом месте экрана.
- Опциональный запуск вместе с Windows.
